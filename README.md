## Python experiments

This repo will be used for the following purposes
- Illustrating the use of python concepts from the very basics - as in "print"ing, reading files and general I/O etc. 
- Using python DICOM library to process dcm files applying python grouping concepts like lists, arrays, dictionaries etc.
- Kaggle datasets will be used when necessary. For eg. - Using DICOM dataset from - https://www.kaggle.com/datasets/aryashah2k/hippocampal-sparing-dataset
